## 四、实体消歧规则

### 4.1 同名/模糊实体优先级

当用户输入可匹配多个实体时，按以下优先级排序：

1. **已上线的影片** > 未上线的影片
2. **有排片的影片** > 无排片的影片
3. **评分高的影片** > 评分低的影片（用户未指定排序时）
4. **距用户近的影院** > 距用户远的影院
5. **用户历史去过的影院** > 未去过的影院

## 六、输入预处理规则

### 6.1 文本规范化
- 全角字母数字 → 半角：`ＡＢＣ１２３` → `ABC123`
- 全角标点 → 半角：`，。！？` → `, . ! ?`
- 去除首尾空白和多余空格
- 统一间隔号：`•` / `‧` / `·` → `·`（中文间隔号）
- 罗马数字 → 阿拉伯数字：`II` → `2`，`III` → `3`

### 6.2 拼音纠错提示
- `zh`↔`z`、`ch`↔`c`、`sh`↔`s`（平翘舌混淆）
- `n`↔`l`（鼻边音混淆，如"呢吒"→"哪吒"）
- `an`↔`ang`、`en`↔`eng`、`in`↔`ing`（前后鼻音混淆）
- `h`↔`f`（如"飞驰"↔"辉驰"）
- `r`↔`l`（如"热辣"↔"乐辣"）

## 七、RAG 检索建议

### 7.1 触发时机
当用户输入满足以下任一条件时，应检索本文档进行纠错：
1. 用户输入中存在明显错别字或拼音错误
2. 用户使用了简称/昵称而非标准名称
3. 用户意图模糊，需要消歧
4. 工具调用返回空结果，可能是输入不准确导致

### 7.2 纠错策略
1. **静默纠错**：置信度 > 90% 时，直接修正后调用工具，不告知用户纠错过程
2. **确认纠错**：置信度 50%-90% 时，修正后向用户确认："您是想找《XXX》对吗？"
3. **追问澄清**：置信度 < 50% 时，列出可能匹配项让用户选择

### 7.3 反馈学习
- 用户纠正过 AI 的映射 → 记录为高优先级规则
- 用户接受纠错 → 提升该映射的置信度
- 用户拒绝纠错 → 降低该映射的置信度
