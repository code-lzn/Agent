本模块来源于电影票智能体产品规格说明书中第2部分——C端前端（对话购票）和第4部分——B端前端（后台管理）。当前公司缺乏统一的在线选座购票系统，用户购票需通过第三方平台。本系统旨在通过 AI 对话式交互，让用户以自然语言完成从选片到出票的全流程购票体验，同时为运营人员提供后台内容管理和数据看板。

# 第一篇：C端前端（对话购票）

## 1. 模块概述

### 1.1 模块定位

C端前端是面向**购票用户**的H5对话式购票界面，采用"文本对话 + 动态卡片"双模交互。用户通过自然语言表达观影需求，Agent智能引导完成从选片到出票全流程，**全程无需页面跳转**。

```
┌─────────────────────────────────────────────────────────────┐
│  ★ 本模块：C端前端 (Text + Cards)                          │
│  技术栈: React + TypeScript + Umi + Ant Design Mobile      │
│  ┌───────────────────┐  ┌──────────────────────────────┐   │
│  │  💬 对话窗口       │  │  📱 动态卡片展示区            │   │
│  │  - 文本输入+发送   │  │  - 8种业务卡片组件            │   │
│  │  - 聊天气泡+ Chips │  │  - 卡片与文本联动             │   │
│  │  - 购票进度条      │  │  - 响应式移动端适配           │   │
│  └───────────────────┘  └──────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                           ↕ HTTP (POST /api/chat/send)
┌─────────────────────────────────────────────────────────────┐
│        后端API + AI Agent                                   │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 功能模块

本模块核心功能包括：

1. **对话交互**：多行文本输入（自扩展）、聊天气泡展示（用户/Agent双角色）、消息历史滚动加载、输入法兼容
2. **快捷建议Chips**：基于当前对话阶段动态生成建议词，横向滑动，点击自动发送
3. **购票进度条**：6步可视化购票进度（选片→选影院→选场次→选座→下单→支付），支持跳步展示
4. **动态卡片渲染**：卡片引擎根据类型分发，8种业务卡片（影片列表/影院列表/场次列表/★座位图/订单确认/支付/出票/异常推荐）
5. **对话-卡片联动**：用户文本→Agent回复+卡片推送；卡片操作→发回Agent→更新对话
6. **状态管理**：Zustand统一管理消息列表、槽位缓存、进度状态、Loading态
7. **移动端适配**：postcss-px-to-viewport（375px设计稿），响应式vw布局

## 4. 核心组件设计

### 4.1 对话输入框 (`ChatInput`)

```typescript
interface ChatInputProps {
  placeholder?: string;
  disabled?: boolean;
  onSend: (message: string) => void;
}
```

| 规格 | 实现 |
|------|------|
| 多行输入 | `<textarea>`, height自扩展(max 4行) |
| Enter发送 | onKeyDown: Enter且非Shift且非输入法组合态→发送 |
| Shift+Enter换行 | 默认行为 |
| 空消息拦截 | trim后为空不触发 |
| placeholder | 初始"说说你想看什么电影吧～"，有历史后"继续输入..." |
| 发送中 | loading动画，按钮置灰 |

```tsx
const ChatInput: React.FC<ChatInputProps> = ({ onSend, disabled }) => {
  const [value, setValue] = useState('');
  const [isComposing, setIsComposing] = useState(false);

  const handleSend = () => {
    const trimmed = value.trim();
    if (!trimmed || disabled) return;
    onSend(trimmed);
    setValue('');
  };

  const handleKeyDown = (e: React.KeyboardEvent) => {
    if (e.key === 'Enter' && !e.shiftKey && !isComposing) {
      e.preventDefault(); handleSend();
    }
  };

  return (
    <div className={styles.inputBar}>
      <textarea value={value} onChange={e => setValue(e.target.value)}
        onKeyDown={handleKeyDown} onCompositionStart={() => setIsComposing(true)}
        onCompositionEnd={() => setIsComposing(false)}
        placeholder="说说你想看什么电影吧～" rows={1} disabled={disabled} />
      <button onClick={handleSend} disabled={disabled || !value.trim()}><SendIcon /></button>
    </div>
  );
};
```

## 6. 状态管理 (Zustand)

```typescript
interface ChatStore {
  sessionId: string | null;
  messages: ChatMessage[];
  currentNode: string;
  completed: string[];
  isLoading: boolean;

  sendMessage: (text: string) => Promise<void>;
  handleCardAction: (action: CardAction) => Promise<void>;
  initSession: (sessionId?: string) => void;
}

const useChatStore = create<ChatStore>((set, get) => ({
  messages: [], currentNode: 'GREETING', completed: [], isLoading: false,

  sendMessage: async (text: string) => {
    set({ isLoading: true });
    // 1. 追加用户消息
    set(s => ({ messages: [...s.messages, { id: uuid(), role:'user', text, timestamp:Date.now() }] }));
    // 2. 调用API
    const res = await chatApi.send({ sessionId: get().sessionId, message: text });
    if (!get().sessionId) set({ sessionId: res.sessionId });
    // 3. 追加Agent消息 + 卡片
    set(s => ({ messages: [...s.messages, { id: uuid(), role:'agent', text: res.reply.text,
      emotion: res.reply.emotion, chips: res.cards?.flatMap(c=>c.chips||[]), cards: res.cards }] }));
    // 4. 更新进度
    set({ currentNode: res.progress.currentNode, completed: res.progress.completed, isLoading: false });
  },

  handleCardAction: async (action) => {
    set({ isLoading: true });
    const res = await chatApi.action({ sessionId: get().sessionId, action });
    /* ...同sendMessage的3-4步... */
    set({ isLoading: false });
  },
}));
```

## 10. C端关键技术设计

### 10.1 卡片渲染引擎设计

采用"类型注册表 + 动态渲染"模式，支持卡片类型扩展：

```typescript
// 卡片注册表 — O(1)查找
const CARD_MAP: Record<string, React.FC<any>> = {
  movie_list: MovieListCard,
  cinema_list: CinemaListCard,
  showtime_list: ShowtimeListCard,
  seat_map: SeatMapCard,
  order_confirm: OrderConfirmCard,
  payment: PaymentCard,
  ticket: TicketCard,
  exception_recommend: ExceptionCard,
};

// 引擎渲染
const CardRenderer: React.FC<{ cards: CardData[] }> = ({ cards }) => (
  <>
    {cards.map(card => {
      const Comp = CARD_MAP[card.type];
      if (!Comp) { console.warn(`Unknown card type: ${card.type}`); return null; }
      return <Comp key={card.type} data={card.data} chips={card.chips} />;
    })}
  </>
);
```

**设计要点：**
- 卡片类型由后端Agent决定，前端仅负责渲染
- 未知卡片类型降级处理（console.warn + 不渲染），不影响对话流
- 卡片之间独立，不共享状态（通过Zustand全局状态通信）

### 15.4 场次管理 (`/content/showtimes`、`/content/showtimes/create`)

**列表筛选：** 影片/影院/日期/状态

**新增/编辑表单：**

| 字段 | 组件 | 说明 |
|------|------|------|
| 关联影片 | Select(搜索) | 已发布影片 |
| 关联影院 | Select(级联) | 选影院后加载影厅 |
| 关联影厅 | Select(级联) | 根据影院过滤 |
| 放映日期 | DatePicker | — |
| 放映时间 | TimePicker | — |
| 散场时间 | 自动计算 | 放映时间+影片时长+15min |
| 标准票价 | InputNumber | 保留2位小数 |
| VIP/情侣票价 | InputNumber | 可选 |

**排片冲突校验：** 提交前调用 `POST /api/admin/showtimes/check-conflict` → 冲突时显示红色提示并阻止提交。

**批量排片：** 选1部影片 → 勾选多个影院 → 设置时间段 → 一键批量创建。

### 15.5 配置管理

**推荐策略 (`/settings/strategy`)：**
- 策略选择器（价格优先/体验优先/距离优先）
- 5个权重滑块（Slider）：价格30% / 评分25% / 距离25% / 时间15% / 座位5%
- 实时校验5项之和=100%

**系统参数 (`/settings/system`)：**
- 锁座时长(InputNumber, 默认15分钟)
- 对话开场白(TextArea)
- Chips预设话术(Select标签模式)

**对话模板 (`/settings/dialogue`)：** 按场景(追问/异常/情感化)编辑模板文本，支持变量 {film} {time} 等。

### 15.6 用户与订单管理

**用户列表：** 用户名/手机/偏好标签/订单数/注册时间 → 详情弹窗(画像+历史订单)

**订单列表：** 订单号/用户/影片/影院/场次/座位/金额/状态/时间 → 筛选(状态/时间范围) → 手动释放(待支付订单)

### 19.2 排片冲突实时校验

提交场次前调用check-conflict接口，冲突时前端红色高亮提示：

```typescript
const checkConflict = async (values: ShowtimeFormValues) => {
  const { hasConflict, conflicts } = await showtimeApi.checkConflict({
    hallId: values.hallId,
    showDate: values.showDate,
    startTime: values.startTime,
    endTime: values.endTime, // 自动计算
  });
  if (hasConflict) {
    message.error(`与以下场次冲突：${conflicts.map(c => c.startTime + '-' + c.endTime).join(', ')}`);
    return false;
  }
  return true;
};
```

### 19.3 批量排片笛卡尔积展开

```typescript
// 选1部影片 + 勾选N个影院 → 一键批量创建
const generateBatchShowtimes = (
  filmId: number, cinemaIds: number[], hallIds: number[],
  dateRange: [Date, Date], timeSlots: string[], price: number
) => {
  // 笛卡尔积展开：cinemaIds × 日期 × 时间段
  const combinations = [];
  for (const cinemaId of cinemaIds) {
    for (let d = dateRange[0]; d <= dateRange[1]; d = dayjs(d).add(1, 'day').toDate()) {
      for (const time of timeSlots) {
        combinations.push({ filmId, cinemaId, hallId: /*匹配的影厅*/, showDate: d, startTime: time, price });
      }
    }
  }
  return showtimeApi.batchCreate(combinations);
};
```

const validateWeights = (weights: Record<string, number>): boolean => {
